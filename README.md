# 🎨 Processing Exercises – Physics for Multimedia

This repository contains a collection of exercises developed using **Processing** as part of the course *Physics for Multimedia*.

The main goal of this repository is to document my learning journey while exploring the Processing language and applying physical concepts through visual and interactive simulations.

---

## 📚 About the Project

In this repository, you will find different sketches that combine:

- 🧮 Basic physics principles (motion, forces, collisions, etc.)
- 🎥 Visual simulations
- 💡 Creative coding techniques using Processing

Each exercise is designed to reinforce both programming skills and the understanding of physical concepts in a multimedia context.

---

## 🚀 Objectives

- Learn and practice the **Processing** programming language  
- Apply **physics concepts** through visual simulations  
- Develop **interactive and graphical thinking**  
- Build a portfolio of small creative coding projects  

---
## 🛠️ Technologies Used

- [Processing](https://processing.org/)
- Java-based syntax (Processing environment)

---

## 📖 What I'm Learning

Some of the concepts explored include:

- Motion and velocity
- Acceleration
- Collisions and boundaries
- Forces and vectors
- Circular motion
- Interactive input

---

## 💻 How to Run

1. Download and install **Processing** from the official website  
2. Clone this repository:

```bash
git clone https://github.com/claudiacordobam/Processing_Exercises.git
```

3. Open any .pde file using Processing
4. Click Run ▶️
